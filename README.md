# 口袋游乐场 · Pocket Play

一个优先为手机设计的 Vue 3 + TypeScript + Vite 纯前端小游戏网站。无需登录与后端服务。

## 本地启动

```bash
npm install
npm run dev
```

访问终端显示的本地地址 `/game/`（例如 `http://localhost:5173/game/`）。手机与电脑处于同一个 Wi-Fi 时，可通过终端显示的 Network 地址访问（电脑需允许防火墙放行该端口）。

```bash
npm run build    # 类型检查并构建到 dist/
npm run preview  # 预览生产构建
npm test         # 验证 2048、扫雷、消消乐、小鸟物理与沙画收集规则
```

## 功能

- 首页游戏列表、分类筛选、名称搜索、随机游戏
- 收藏与最近游玩，localStorage 保存本机最高纪录
- 沙画消消：8 幅原创沙画（3～8 色）、四列前排点选桶、200～1200 主容量与按沙量补齐的尾桶、四列混色队列、底部 6 层同色收集、6 位横向传送带（移动速度提高一倍）、三同色桶容量相加合成、满桶即时消失、胜负判定与全部关卡自由选择。手机竖屏使用一屏布局，支持暂停、说明、重开确认与后台自动暂停；入口为 `#/play/sand`。模拟使用 160×160 类型数组、30 Hz 固定更新、休眠行与列底部缓存，流沙特效最多 96 个粒子。钥匙、锁和消耗道具留待后续版本
- 开心消消乐：7×7 动物棋盘、点击/滑动交换、三连消除、连锁掉落、25 步 1500 分目标、免费提示、无可用组合自动重排。每局免费提供小木锤 ×3、十字火箭 ×1、彩虹魔法 ×1、魔法重排 ×2；道具不扣步数，重开恢复数量
- 2048：直接滑动、电脑键盘方向键、撤回一步、胜利后继续
- 愤怒的小鸟：拖动弹弓、轨迹预览、Matter.js 物理碰撞、可倒塌的木架与石墙、5 个关卡、星级评价、小鸟剩余奖励、暂停与重玩。手机横屏自动使用沉浸式布局，竖屏显示旋转提示并暂停，旋转保留当前进度；提供全屏按钮，浏览器支持时尝试锁定横屏，不支持时手动旋转即可。切到后台自动暂停。电脑可聚焦棋盘后按空格发射推荐角度
- 记忆翻牌：16 张卡片、8 组配对、计时、步数
- 打地鼠：30 秒挑战、单次命中计分
- 扫雷：8×8 棋盘、10 颗雷、首击安全、插旗模式、右键插旗
- 反应测试：随机等待、抢跑提示、5 轮平均成绩

使用 hash 路由，当前构建部署前缀为 `/game/`。将 dist/ 的内容上传到 `/opt/game/`，将 deploy/game.conf 放到 `/etc/nginx/conf.d/game.conf` 并停用旧的 image-view.conf；这份完整配置同时承载游戏、原图片站与 API，无需额外 include。完整步骤见 [Linux 部署说明](deploy/README.md)。如果需要部署在其他路径，修改 vite.config.ts 中的 base 后重新构建。搜索、游戏插画、游戏逻辑均由前端实现。Google Fonts 用于增强排版；网络不可用时自动回退系统字体，游戏不受影响。

各游戏组件位于 src/games/；新增游戏时更新 src/data.ts、GameRoom.vue 的组件映射与 GameArt.vue 插画即可。浏览器清理站点数据后，本机收藏与纪录会重置。

修改沙画或模拟规则后，可运行 `node scripts/generate-sand-levels.mjs` 重新生成沙桶队列和通关回放，然后运行 `npm run test` 验证所有关卡。
